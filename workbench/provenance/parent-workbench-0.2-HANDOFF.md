## Important implementation details

`coverage-facets/1` IDs are stable semantic facets rather than attack verdicts. Allocation uses whole dependency closures, deduplicates case/layout/repetition jobs, rejects partial mandatory coverage and continues after unaffordable groups. It is greedy, not an optimal solver. Budget-dependent exploration means monotonic subset nesting is not promised across different budgets. Preserve the plan and seed for reproducibility.

Raw metadata responses are source/request/model/hash validated. Execution also requires the same response hash settled in the original account. This is local evidence integrity, not provider-signed attestation. Thresholds for uncertain rankings and tag proposals are explicit heuristics; never relabel them calibrated correctness.

No new case expected answers or target request content are derived from advice. The fixed per-question examples are unchanged. Reports distinguish selector metadata and target findings. The old app remains available in its parent archive as the previous measurement/control release.
