# Roadmap after 0.2

## Implemented now

Policy editor and native renderer, application-context relevance advice, bounded independent taxonomy suggestions, 32 granular units / 60 cases, mandatory coverage and independent exploration, budget allocation, explicit metadata + evaluation execution on the same ledger, cache/report identity validation, evidence UI and source handoff.

## Next empirical validation

Measure advice correctness against reviewed applicability labels; compare equal-cost suites selected with mandatory-only, seeded, neutral granular and Jev-ranked strategies. Do not infer selection quality from the software tests.

## Next engineering

Integrate historical replay/scoring as a separate adapter without relabeling its 15,120 cells as admission tests. Keep stable descriptor grouping and provenance. Extend incremental preparation/report persistence and simulate the actual full payload pipeline before advertising full live campaign support. Imported family tagging is not that integration.

Add owner-reviewed registry edits from tagging proposals, richer external catalogs, customer-owned cases with independently reviewed labels, and realistic full-window context panels. Free-form synthesis, public uploads, multi-tenant hosting, adaptive attack generation and production effects remain future features.
