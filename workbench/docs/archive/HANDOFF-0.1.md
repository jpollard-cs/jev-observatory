## Decisions carried forward

- Jev-first native request surfaces; model-neutral/canonical source handling preserved through the vendored compiler.
- One explicit policy configuration rather than an opaque, ever-growing universal prompt.
- Semantic attack, representation violation, language violation, relevance, and admission remain distinct.
- Strict, contextual and isolated inspection are operating contracts, not levels of guaranteed security.
- English-only is a configuration default, not a proof of lower attack success. “Any language” is permission, not demonstrated universal coverage.
- Consumer context resolves through named shared/entry fields. Content cannot appoint itself as trusted context or grant an exception.
- Both example placements remain available because the latest measurement did not establish a universal winner.
- Deterministic consequences are computed in code from the same saved semantic findings. They remain separately scored from Jev's native disposition.
- New context cases contain coherent source records and task-evidence questions, not inert padding. They are still small synthetic dossiers, not full-window or real-agent episodes.
- No automatic paid inference or publication from the browser. Keys remain in the local project/account environment.
